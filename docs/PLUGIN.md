# Skedra plugin for self-hosted instances

The plugin source is included in plugins/skedra. Configure its MCP server URL for
your own installation before packaging or installing it. The public Skedra website
is documentation only and does not provide an MCP endpoint or Cloud accounts.

Use the configuration generated by **Settings > API Keys & MCP** on your instance.
For client setup, permissions and encryption, see [MCP.md](MCP.md).

Previously submitted hosted plugins and MCP registry entries need a separate
update or withdrawal when retiring the hosted service. Do not submit a package
pointing to the old central endpoint.
