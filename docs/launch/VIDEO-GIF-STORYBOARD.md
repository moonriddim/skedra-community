# Demo video and GIF storyboard

Target: one 42–48 second master video, one silent 12-second product-loop GIF,
and three short still clips for posts.

## Master video

| Time | Picture | Caption |
| --- | --- | --- |
| 0–4s | Empty Skedra board beside the AI client | “What if your agent had a real whiteboard?” |
| 4–10s | Paste the golden prompt | “One prompt. Structured canvas tools.” |

## Recording settings

- Record at 1920×1080, 60 fps; publish MP4/H.264 at 1080p.
- Crop out bookmarks, personal accounts, notifications and operating-system UI.
- Use 125–140% editor zoom and a large AI-client font.
- Keep pointer movement slow and intentional; remove waits longer than 700 ms.
- Add burned-in captions and provide an accurate subtitle file.
- Use gentle 200–300 ms cuts; avoid fake typing and dramatic zoom effects.

## 12-second GIF loop

1. Start on the prompt.
2. Cut to the empty board.
3. Show Kanban and Gantt appearing.
4. End on a card moving from In progress to Ready.
5. Match the last frame to the first as closely as possible.

Export at 1200×675, 15–20 fps and below 8 MB. Prefer WebM/MP4 where the
community accepts video; use GIF only where autoplay support requires it.

Suggested alt text: “An AI client uses Skedra MCP to create an editable Kanban
board and Gantt timeline, then updates one task while the board stays live.”
