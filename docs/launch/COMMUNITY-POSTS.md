# Community announcement draft

Skedra is becoming a fully open-source, self-hosted whiteboard under AGPL-3.0-only.
The complete app, collaboration backend, MCP server and React SDK are developed
in one repository: https://github.com/moonriddim/skedra-community.

The website provides documentation, installation instructions and project links.
Run Skedra on your own NAS, VPS or server without a Skedra subscription.

Publish this announcement only after the public changes and images are available.
