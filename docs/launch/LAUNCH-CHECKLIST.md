# Open-source transition checklist

- Merge the reviewed transition into the existing public repository.
- Verify CI, container publishing and npm trusted publishing from that repository.
- Publish a release containing the AGPL license and self-hosting files.
- Preview and deploy apps/docs/dist to the public domain.
- Complete hosted-user data exports and resolve existing subscriptions.
- Update or withdraw old hosted MCP and plugin submissions.
- Retire old service infrastructure, archive the private repository and remove
  retired deployment keys only after confirming the transition.

See [OPEN-SOURCE-TRANSITION.md](../OPEN-SOURCE-TRANSITION.md).
